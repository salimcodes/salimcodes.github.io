# AfriTabooBench (PRIVATE data repo)

Raw responses from the AfriTaboo Phase 1 elicitation form. **Keep this repository private**: it contains self-reported ethnicity, religion and other sensitive attributes.

```
submissions/<participant-id>/<submission-id>.json   raw submissions, written by the form backend
exports/taboos.csv                                  one row per taboo (rebuilt automatically)
exports/participants.csv                            one row per participant
exports/submissions.csv                             audit log and feedback
exports/SUMMARY.md                                  live counts by country, theme, group
scripts/build_exports.py                            builds exports/ (standard library only)
```

`exports/` is regenerated by GitHub Actions on every new submission. Don't edit it by hand.

## Withdrawal requests

Delete the participant's folder and push:

```bash
git rm -r submissions/AT-XXXX-XX && git commit -m "Withdraw AT-XXXX-XX" && git push
```

The exports rebuild without them. Their data still exists in git history; if you need it erased completely, rewrite history with `git filter-repo` before any data is released.

## Releasing the dataset

Before publishing anything, build a release from `exports/taboos.csv` that drops `user_id` and free-text fields that could identify someone, and coarsens small groups (for example, merge any group with fewer than 5 participants into "other").
